2. **Database:** Absolutely NO raw SQL (Drizzle ONLY). Tables MUST include `users` and foreign keys `userId` on all data tables.

7. **Installation:** All `pnpm add` commands MUST include the `-E` flag.
8. **Environment:** Wrap ALL config strings containing special characters in `.env` with single quotes. MANDATORY dynamic import for `bcryptjs` in Server Actions.
