* `git init`: Khởi tạo một kho lưu trữ Git mới trong thư mục hiện tại.
* `git config --global user.name "Tên Của Bạn"`: Cài đặt tên hiển thị cho tất cả commit.
* `git config --global user.email "email@example.com"`: Cài đặt email liên kết với các commit.
* `git clone <đường-dẫn-url>`: Sao chép một kho lưu trữ từ máy chủ về máy cục bộ.
---
* `git switch <tên-nhánh>`: Chuyển sang một nhánh khác.
* `git switch -c <tên-nhánh>`: Tạo một nhánh mới và chuyển ngay sang nhánh đó.
* `git branch -d <tên-nhánh>`: Xóa một nhánh an toàn sau khi đã gộp code.
* `git branch -D <tên-nhánh>`: Ép buộc xóa một nhánh ngay cả khi chưa gộp code.
---
* `git status`: Kiểm tra trạng thái hiện tại của các file.
* `git add <tên-file>`: Đưa một file cụ thể vào vùng chuẩn bị (Staging Area).
* `git add .`: Đưa toàn bộ các file có thay đổi vào vùng chuẩn bị.
* `git commit -m "tin-nhắn-commit"`: Lưu lại ảnh chụp code kèm theo mô tả ngắn gọn.
* `git commit --amend -m "tin-nhắn-mới"`: Sửa nhanh nội dung/tin nhắn của commit gần nhất (khi chưa push).
---
* `git remote add origin <đường-dẫn-url>`: Liên kết kho lưu trữ cục bộ với kho lưu trữ trên mạng.
* `git fetch`: Tải về toàn bộ lịch sử và các nhánh mới từ máy chủ (chưa gộp vào code hiện tại).
* `git pull origin <tên-nhánh>`: Tải code mới nhất từ máy chủ về và tự động gộp vào nhánh hiện tại.
* `git push origin <tên-nhánh>`: Đẩy các commit từ máy cục bộ lên máy chủ.
---
* `git restore <tên-file>`: Hủy bỏ các thay đổi chưa commit trên một file, đưa file về trạng thái cũ.
* `git restore --staged <tên-file>`: Đưa file ra khỏi vùng chuẩn bị nhưng giữ nguyên nội dung đã sửa.
* `git revert <mã-commit>`: Tạo commit mới để đảo ngược code của commit lỗi (An toàn cho làm việc nhóm).
* `git reset --hard <mã-commit>`: Xóa sổ hoàn toàn lịch sử và code để quay về quá khứ (Chỉ dùng khi làm một mình).
---
* `git stash push -m "ghi-chú"`: Cất tạm code đang viết dở vào kho lưu trữ tạm thời kèm ghi chú.
* `git stash pop`: Lấy lại code vừa cất tạm gần nhất để tiếp tục làm việc và xóa nó khỏi kho lưu trữ tạm.
* `git stash list`: Xem danh sách tất cả các gói code đang được cất tạm.
* `git merge <tên-nhánh>`: Gộp code từ nhánh khác vào nhánh hiện tại.
* `git rebase <tên-nhánh>`: Tái cấu trúc lịch sử, đặt các commit của nhánh hiện tại lên đầu nhánh khác.
* `git cherry-pick <mã-commit>`: Bốc duy nhất một commit cụ thể từ nhánh khác áp dụng vào nhánh hiện tại.
---
* `git log --oneline --graph --all`: Xem toàn bộ lịch sử commit dưới dạng sơ đồ hình cây trực quan.
* `git diff`: Xem chi tiết các dòng code thay đổi chưa được add.
* `git show <mã-commit>`: Xem chi tiết nội dung thay đổi của một commit cụ thể.
